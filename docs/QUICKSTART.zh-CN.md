# 快速开始（面向完全不懂技术的人）

这份指南假设你从没用过命令行。跟着点就行。

## 你能得到什么

装好之后，你在 AI 助手里用大白话问一句「有没有货要发」「这个月发了哪些机器」，它就直接给你整理好的答案，还能导出 Excel。

## 第一步：装三样东西

**1. 装一个 AI 助手**（WorkBuddy、Goodax、DeepSeek、Harness 等，任选一个你顺手的）。

**2. 装水宝客户端**

打开 <https://jxy.ai/download> → 点「Windows 版本」下载 → 一路下一步装好。
（产品介绍：<https://www.juxieyun.com/shuibao>；如果公司统一发了安装包，用公司那份。）

> 安装时如果提示要装「水宝守护服务」，点允许，这是正常组件，不用管它。

**3. 用你自己的账号登录水宝**

打开水宝，用**你自己的**聚水潭账号登录一次。没有账号？先找公司开通，这一步谁都帮不了你。
登录完不用一直开着水宝。

**4. 点一次授权**

打开水宝 → 找到「连接管理」（不在"设置"里）→ 找到「聚水潭」→ 点「授权」。
这步必须**你本人**点，只做一次，以后都不用再做。

## 第二步：装这个助手

在你的 AI 助手里：

- 把这个技能装进你的 AI 助手（把仓库里的 `skill/` 目录作为技能安装，这是主用法）；
- 想要更强的 MCP 工具，再配置 `mcp/` 里的标准 MCP Server（可选，支持 MCP 的助手用）。

装好后，直接对着 AI 说话就行，比如：

> 查一下现在还有多少库存

第一次问的时候，AI 会自动检查环境，缺哪一步就只告诉你那一步怎么做——一次只说一件事，不会甩给你一堆术语。你按它说的做完，回一句「好了」，它会自己再检查一遍。

## 第三步：这样问

| 你想知道 | 就这么说 |
| --- | --- |
| 生意概况 | 「今天生意怎么样」 |
| 待发货 | 「有没有货要发」 |
| 发货序列号 | 「这个月发了哪些机器」，「导出成 Excel」 |
| 反查机器 | 「客户报了个序列号 SN-DEMO-0001，是哪单发的」 |
| 库存 | 「还有多少库存」，「哪些货快没了」 |
| 某笔订单 | 「订单 xxx 发了吗」 |
| 售后/采购 | 「查一下最近的售后退款」 |
| 能查什么 | 「都能查什么」 |

结果是中文表格 + 一句话结论。要存成表格就说「导出 CSV」，Excel 双击就能打开。

完整清单见 [场景说明](SCENARIOS.zh-CN.md)。

## 记住四件事

1. **水宝只在装、登录、授权、续期这四个时刻要开着**，平时查数据可以关。
2. **登录约 7 天过期**，到时候 AI 会提醒你重新登录一次；授权不用再点。
3. **每个人用自己的账号**，包可以共用，凭据不能共用。
4. **它是只读的**，发货、审核、改单这些它做不了也不会做。

## 卡住了怎么办

- 先搜「常见问题」[FAQ](FAQ.zh-CN.md)，八成问题在那儿。
- 还是不行，看 AI 给你的提示里那句英文代码，连同你的环境（系统 / 水宝版本）一起提 Issue。贴日志前**记得打码账号、序列号、客户信息**。
