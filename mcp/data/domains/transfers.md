# 调拨

## 用户目标

查询或处理跨仓调拨、仓内调拨、调拨确认、取消及差异单。

## 能力路由

| 业务能力 | 类型 | action |
| --- | --- | --- |
| 跨仓调拨上传 | 写入 | `allocate_kc_upload` |
| 仓内调拨上传 | 写入 | `jushuitan_allocate_in_upload` |
| 调拨单查询 | 查询 | `allocate_query` |
| 调拨单确认 | 写入 | `jushuitan_allocate_confirm` |
| 调拨单取消 | 写入 | `jushuitan_allocate_cancel_v2` |
| 调拨差异单上传 | 写入 | `jushuitan_diffallocate_create` |

## 执行要点

- 先区分跨仓调拨与同一公司账号内的仓内调拨，明确调出仓、调入仓及相关分仓编号。
- 创建前可读取[库存](inventory.md)核对调出仓库存，但查询库存只能辅助判断，不能自动替用户决定调拨数量。
- 跨仓调拨可能经历待审核、已确认、调拨中、待收货和完成等阶段；是否启用“非销售出库单据占有库存”会影响状态流转。
- 调拨查询需要结合调出单和调入单状态解释ERP页面状态，不要只读取单一状态字段下结论。
- 确认接口只支持符合官方状态的单据；主仓确认分仓单时需要正确的分仓编号。
- 取消仅支持本仓且符合状态要求的单据，推送到三方仓的单据可能无法作废。
- 差异单必须关联已确认的调拨入单，差异数可以为负数；需要说明正负代表的实际差异方向。
- 虚拟仓之间的业务使用[虚拟仓](virtual-warehouse.md)，不要混用实体仓调拨。

## 结果呈现

- 调拨结果展示调拨单号、调出仓、调入仓、当前阶段、计划数量、已出数量、已入数量和差异。
- 跨仓进度按“调出完成”和“调入完成”分别说明；只看到调出单不能宣称整个调拨完成。
- 差异数量保留正负号，并用文字说明是多收、少收或接口定义中的对应方向。
- 创建、确认、取消和差异上报分别形成回执；失败时指出是状态不允许、本仓限制还是三方仓限制。

## 典型问题

- “TR001 到上海仓了吗？”：同时核对调出、在途、调入和差异状态。
- “从北京仓调100件A001到上海仓”：先核对两个仓和调出库存，提交后给出调拨单号及计划数量。
- “这批调拨少收了几件？”：展示计划、已出、已入和差异方向，不只返回差异原值。
